Get started with Real-Time Dashboards in Microsoft Fabric
Real-time dashboards in Microsoft Fabric enable you to visualise and explore streaming data using the Kusto Query Language (KQL). In this exercise, you’ll explore how to create and use a real-time dashboard based on a real-time data source.


In this hands-on, you'll be experiencing the following things


1. Create a workspace
2. Create an event house
3. Create an event stream
4. Create a real-time dashboard
5. Create a base query
6. Add a parameter
7. Add a page
8. Configure auto refresh
9. Save and share the dashboard
