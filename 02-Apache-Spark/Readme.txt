Analyze data with Apache Spark in Fabric
In this lab you will ingest data into the Fabric lakehouse and use PySpark to read and analyze the data.


Caution:
This is common step for all hands on
Attach the lakehouse to the notebook and also grant the permission from the Lake house home page by using the share icon and in that mention the user as the the email id you are using in the fabric trail account

In this Hand - on you'll be experiencing the following things

1. Create a workspace
2. Create a lakehouse and upload files
3. Create a notebook
4. Create a DataFrame
5. Explore data in a DataFrame
6. Use Spark to transform data files
7. Work with tables and SQL
8. Visualize data with Spark
9. Clean up resources
