Use Delta Tables in Apache Spark
Tables in a Microsoft Fabric Lakehouse are based on the open-source Delta Lake format. Delta Lake adds support for relational semantics for both batch and streaming data. In this exercise you will create Delta tables and explore the data using SQL queries.


Caution
This is common step for all hands on
Attach the lakehouse to the notebook and also grant the permission from the Lake house home page by using the share icon and in that mention the user as the the email id you are using in the fabric trail account

In this Hand - on you'll be experiencing the following things

1. Create a workspace
2. Create a lakehouse and upload files
3. Explore data in a DataFrame
4. Create a Delta table
5. Explore table versioning
6. Analyze Delta table data with SQL queries
7. Use Delta tables for streaming data
