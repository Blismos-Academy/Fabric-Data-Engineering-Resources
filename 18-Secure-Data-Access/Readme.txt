Secure data access in Microsoft Fabric
Microsoft Fabric has a multi-layer security model for managing data access. Security can be set for an entire workspace, for individual items, or through granular permissions in each Fabric engine. In this exercise, you secure data using workspace, and item access controls and One Lake data access roles.



In this hands-on, you'll be experiencing the following things


1. Create a workspace
2. Create a data warehouse
3. Create a lakehouse
4. Apply workspace access controls
5. Apply item access control
6. Apply One Lake security in a lake house
